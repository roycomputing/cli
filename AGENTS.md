# Contributing

Use Node 26 and pnpm 12. Run `pnpm install --frozen-lockfile`, `pnpm check`, `pnpm test` and `pnpm exec oxfmt --check`.

This repository and its build logs are public. Use public API shapes, synthetic fixtures and independently installable dependencies. Keep private infrastructure and customer data out of source, examples and issues. Add dependencies only when explicitly requested. Put contributor notes in `agent-notes/` when needed.
